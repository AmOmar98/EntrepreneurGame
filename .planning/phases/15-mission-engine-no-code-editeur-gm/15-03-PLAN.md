<objective>
Build the missions + deliverable-template editing surface: a GM-only `/admin/events/[id]/missions` page that lists/creates/edits/deactivates/reorders missions (ENGINE-01) and a deliverable-template editor with a dynamic rubric builder (ENGINE-02). Output: `lib/admin-missions.ts` accessor, `/admin/events/[id]/missions` page, two client editor components, four Flow actions, i18n keys.
</objective>
